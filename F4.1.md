# F4.1 Zeroize Logic

## What was added
- **Zeroize crate** added to `caf-core` (`cargo add zeroize`).
- `VaultBackupPayload` now derives `Zeroize` and `ZeroizeOnDrop` to automatically zero its memory when dropped.
- In `backup.rs`, the derived encryption key (`derived_key`) is explicitly zeroized after encryption using `derived_key.zeroize();`.
- Local `use zeroize::Zeroize;` imported within the function where the key is zeroized.

## Rationale
Zeroizing secret material (encryption keys, derived keys) protects against accidental leakage in memory dumps or after a crash. Deriving the key for backup encryption and then zeroing it ensures the secret never remains in RAM longer than necessary.

## Verification
- `cargo clippy` and `cargo test` pass.
- Runtime tests for backup/export/import still succeed, confirming functionality unchanged.
