# F13.3: AI Context Providers & Visibility Integration

## Overview
Implemented `ContextProvider` trait and registry mechanism to allow dynamically aggregating context for AI operations while respecting F9 visibility scopes.

## Implementation details
- **`ai_context.rs`**: Defined `ContextProvider` trait and `ContextManager` registry for context aggregation.
- **`ai_context_notes.rs`**: Implemented `NotesContextProvider` which integrates with F9 `VisibilityScope` to build filtered SQL queries for notes.
- **Audit Compliance (F9.2)**: Included explicit audit logging in `NotesContextProvider` when a super-user role bypasses standard visibility filters via context provider.

## Verification
- Code structure checked with `cargo check`.
- Context providers are correctly registered and utilized within `ContextManager`.
- Visibility scopes are applied to SQL queries dynamically.
- Audit events are properly triggered for super-role bypasses.
