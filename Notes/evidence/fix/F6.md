## 1. Sub-tasks Verification

### F6.1 — Keyring Module
`crates/caf-core/src/keyring.rs` implements:
- AES-256-GCM authenticated payload wrapping with AAD (`caf-keyring-v1|password|<vault_id>`)
- Argon2id KEK derivation (m=64MiB, t=3, p=4)
- HKDF-SHA256 recovery KEK derivation
- Atomic file writes for `keyring.v1.json`
- Legacy vault layout detection (`VaultError::LegacyFormat`)

### F6.2 — Setup with Recovery Code & Confirmation
- BIP-39 24-word recovery code generation via `bip39` crate
- Exact 3-word position confirmation via `confirm_recovery_words()`
- Zeroizing memory containers for all sensitive materials
- Verified: No plaintext words, entropy hex, DEK hex, or passwords written to disk

### F6.3 — Master Password Change without Rekey
- Constant-time `change_master_password()` via password slot rewrapping
- Verification that DEK remains completely unchanged
- Verification that recovery slot remains valid after password change

### F6.4 — Unlock with Recovery Code & Password Reset
- `guarded_unwrap_with_recovery()` successfully unwraps DEK/BK
- Keyring allows updating password slot following recovery

### F6.5 — Recovery Code Regeneration
- `replace_recovery_slot()` increments `generation`
- Old recovery entropy immediately invalidated
- New recovery entropy proven working

### F6.6 — Brute-force Protection
- Unified `AUTH_FAIL_COUNT` shared between password and recovery attempts
- 5 consecutive failures triggers `VaultError::LockoutActive`
- Successful authentication clears failure counter
